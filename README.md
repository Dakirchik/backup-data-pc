# Backup Data PC

Консольная программа резервного копирования папок на Windows через robocopy. Поддерживает несколько компьютеров и несколько папок-источников для каждого устройства. Запускается через меню и хранит копии рядом с программой, поэтому её удобно размещать на внешнем диске.

## Требования

- Windows с Windows PowerShell 5.1 и robocopy.exe.
- Доступ к папкам-источникам и место на диске для резервных копий.

Дополнительные библиотеки устанавливать не требуется.

## Запуск

1. Скачайте или клонируйте репозиторий в папку на диске, где будут храниться копии.
2. Откройте `Start.cmd`.
3. Выберите пункт `2. Добавить устройство` и укажите папки-источники.
4. В главном меню выберите устройство и запустите копирование из его меню.

Личный файл `config/devices.json` создаётся при сохранении настроек через меню. При желании перед первым запуском можно скопировать `config/devices.example.json` в `config/devices.json` — шаблон содержит пустой список устройств.

Программа определяет корень хранения относительно расположения скрипта; фиксированная буква диска не требуется. Для использования на внешнем диске перенесите туда `Start.cmd` и папку `config` с сохранением структуры.

## Как работает копирование

- Копирование одностороннее: из выбранных папок в `data/<устройство>/<источник>/`.
- Используется robocopy с подпапками, без `/MIR` и `/PURGE`: удалённые в источнике файлы остаются в копии.
- Более новые файлы в копии не перезаписываются благодаря `/XO`. Это не система хранения версий: другие обновлённые файлы могут перезаписывать предыдущую копию.
- Файлы с атрибутом Offline (доступные только в облаке) пропускаются. Нужные облачные файлы сначала скачайте на компьютер.
- Служебная папка `.sync` исключается автоматически; дополнительные исключения задаются в настройках устройства.
- Запись устройства привязывается к компьютеру. После переустановки Windows при необходимости выберите в настройках устройства «Привязать к этому компьютеру».

## Структура

```text
Start.cmd                     — запуск меню
config/backup-menu.ps1        — основной код
config/devices.example.json   — пустой шаблон конфигурации
config/devices.json           — личные настройки (не входят в Git)
data/                         — резервные копии (не входят в Git)
logs/report.txt               — читаемый отчёт (не входит в Git)
logs/raw/                     — технические логи (не входят в Git)
```

`data` и `logs` заполняются во время работы. Публикуйте только код и шаблон: личный конфиг содержит имена компьютеров, идентификаторы Windows и пути к папкам, а отчёты — имена и пути файлов.
